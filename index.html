02 / DIE IDEE

C-DROHNE // C-DRONE · BEOBACHTUNGSKONZEPT

Viele Meldungen.
Wenig Gewissheit.

Stell dir vor, drei Nachbarn erzählen dir dasselbe. Wenn alle denselben Anruf weitergeben, hast du eine Quelle gehört, nicht drei unabhängige Zeugen.

Genau diese Verwechslung kann in vernetzten Beobachtungssystemen passieren. C-DROHNE beginnt deshalb mit einer einfachen Reihenfolge: sehen, prüfen, wer die Meldung ursprünglich gemacht hat, andere Erklärungen vergleichen, Menschen entscheiden lassen.

Ein durchgehendes, erfundenes Beispiel: Nach einem Unwetter melden drei Stellen einen möglicherweise versperrten Hilfsweg. Die zweite Meldung kopiert die erste; die dritte ist älter. Zuerst werden Wortlaut, Quelle und Zeit getrennt erfasst. Dann werden die beiden Kopien als ein Herkunftscluster und die ältere Meldung als möglicherweise veraltet markiert. Das Ergebnis lautet: aktueller Zustand offen. Eine zuständige Person prüft eine neue, unabhängige Information, bevor sie eine Entscheidung trifft. Diese Szene erklärt die Methode; sie ist kein ausgeführter Feldeinsatz.

WAS STECKT HINTER DEM C?

Der erste Forschungszweig heißt CHILDDROHNE. Gemeint ist eine neugierige, revidierbare Sicht auf Dinge: Blume, Bumerang, Kinderwagen oder unbekannte Form. Das C bleibt als Spur zum Code erhalten.

PERSPEKTIVE DER BETROFFENEN

Eine falsche Deutung trifft Menschen.

In dieser Seite werden nur erfundene Meldungen und Zeichnungen verarbeitet. Sie macht kein Foto von dir. Für einen späteren Piloten müssen Betroffene vor einer Erfassung verstehen können, was erfasst wird, wozu es dient, wie lange es bleibt und wie sie eine falsche Deutung beanstanden können.

Ein Einwand braucht eine zuständige Person, eine überprüfbare Korrektur und eine Rückmeldung. Der erfundene Fehlalarm unten zeigt diese Sperre im Browser. Ein realer Meldeweg ist ein offener Entwicklungsauftrag. Datenschutzfragen 41–48 prüfen →

Lieferobjekt
Versionierter Quellcode, synthetische Fälle, Sollausgaben, Testprotokoll, Rechteübersicht und eine kurze Bedienanleitung.
Abnahmefrage
Kann eine andere Fachperson das Paket ohne mündliche Hilfe lokal starten, die vereinbarten Fälle nachvollziehen und Abweichungen protokollieren?
Messung vor dem Bau festlegen
Auf denselben synthetischen Fällen werden richtige Herkunftszuordnung, offen gehaltene Unsicherheit, Fehlentscheidungen und Bearbeitungszeit gegen eine einfache manuelle Checkliste verglichen. Testmenge und Schwelle werden vorab vereinbart; eine Erfolgsquote liegt heute nicht vor.
Kleinster Paketplan
  1. Fall- und Rechteklärung mit einer Fachperson
  2. Offline-Demo und reproduzierbare Gegenproben
  3. Unabhängiger Nachlauf, Fehlerliste und Entscheidungsvorlage
Aufwand, Lizenz der neuen Ergebnisse und Vergütung werden je Paket kalkuliert und vereinbart. Bei Datenabfluss, unerwarteter Außenwirkung oder fehlendem Zusatznutzen gegenüber der Checkliste wird der Ansatz angehalten und überarbeitet.
